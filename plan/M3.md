# M3. Theme, shell and snapshot tool

**Read first:** all of `docs/UI_DESIGN.md`; `assets/design-tokens.json`; `assets/theme.qss.tmpl`; `docs/ARCHITECTURE.md` section 1; `docs/UBUNTU_NOTES.md` sections 2 to 4 and 6 to 7.

**Build**
- [ ] Bundle fonts: fetch Instrument Sans and Newsreader (SIL OFL) from the `google/fonts` repository into `assets/fonts/` with license files. Ask the owner to run any command you cannot run. Register at startup; fall back silently and log a warning.
- [ ] `ui/theme.py`: render `theme.qss.tmpl` for light and dark from the tokens, set `QPalette`, apply font families and sizes, System mode follows the desktop, scale-aware sizes.
- [ ] Hand-drawn SVG icons in `assets/icons/` (list in UI_DESIGN section 7), recolored via the theme. Install `tea.svg` and `tea-attention.svg` as app and tray icons.
- [ ] `ui/strings.py` with the microcopy from UI_DESIGN section 8 and the empty states.
- [ ] `app.py` and `ui/main_window.py`: rail with four items, four empty screens using the real empty-state copy, rail footer status line, keyboard shortcuts, size and position memory.
- [ ] Tray icon and menu; close-to-tray; `--background` start; single instance through `QLockFile` and `QLocalServer`.
- [ ] **`devtools/snap.py`**: `python -m tea.devtools.snap <screen> --theme light|dark [--state <name>] [--scale 1.25]` and `--all`. Renders the widget offscreen with `QWidget.grab()` to `.snapshots/<screen>-<state>-<theme>.png`. It runs headless with `QT_QPA_PLATFORM=offscreen`, `FakeClock` and sample data from `devtools/sample_data.py`. Later milestones register their screens and states with it.

**Tests first:** theme renders without unresolved `{{tokens}}`; both modes produce a stylesheet; hex literals appear nowhere under `src/tea/ui/` except `theme.py`; second launch focuses the first instance (test the local-server logic directly); the snapshot tool produces a PNG for each current screen in both themes.

**Acceptance**
1. The app opens in light and dark and follows the system setting.
2. A second `tea` launch focuses the running window. Closing the window keeps the tray icon.
3. Snapshots of the four empty screens in both themes exist and you have compared them with UI_DESIGN sections 1 to 3 (colors, type, spacing, radii, empty-state copy). List any mismatch you could not fix.
4. No hard-coded hex colors, font names or pixel sizes in widgets.
5. `tea doctor` (partial is fine) reports which font families resolved.

Run the `ui-checker` subagent on the snapshots before finishing.
