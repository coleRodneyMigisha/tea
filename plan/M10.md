# M10. Settings, install and doctor

**Read first:** `docs/UI_DESIGN.md` section 3.4; `docs/SPEC.md` section 8; `docs/ARCHITECTURE.md` sections 9, 11, 12; `docs/UBUNTU_NOTES.md` sections 1, 5, 9; `desktop/*.desktop`.

**Build**
- [ ] Complete the Settings screen: every item in UI_DESIGN 3.4, including the interests chips editor and the style notes box. There is no API key and no model setting.
- [ ] `tea install-autostart` and `uninstall-autostart`: render the `.desktop` templates (`__TEA_BIN__` replaced by the absolute path), install icons, fully reversible, no stray files.
- [ ] `tea doctor`: tray available, notification service reachable, fonts resolved, DB healthy and migrated, templates and prompts valid, data dir sizes. Readable output. The Settings "Run checks" button shows the same report.
- [ ] Export backup (zip of DB and uploads) and a restore test into a fresh data dir.
- [ ] A project `README.md` for daily use: install with `pipx`, autostart, the weekly routine, how a hand-off works, how to back up.

**Tests first:** install then uninstall leaves the file system as it was (temp HOME); doctor output for missing tray (mocked) and missing fonts; backup zip restores; settings validation messages; changing the Claude link changes what "Open Claude" opens.

**Acceptance**
1. Install and uninstall autostart are reversible, verified in a temp HOME.
2. Doctor output is accurate for each mocked condition.
3. Backup restores into a fresh data dir and the app starts with the restored data.
4. Settings snapshots in both themes match UI_DESIGN section 3.4.
