# M4. Question system

**Read first:** `docs/SPEC.md` section 6; `docs/UI_DESIGN.md` section 4 (popup); `data/question_bank.json`, `data/focus_question_templates.json`, `data/improve_questions.json`, `data/scope_question_templates.json`; `docs/TESTING.md` section 3 (questions) and section 4 (popup).

**Build**
- [ ] `domain/questions.py`: seed the bank idempotently by `bank_key`; instantiate focus templates (`{focus}`) and improvement templates (`{title}`) into question rows, rejecting unknown placeholders; select scope questions for a manual blog by the rule in `data/scope_question_templates.json` (5 to 15); weighted login selection; no repeats in a session; 14-day rule; cooldown; session mix; skipped stored as skipped.
- [ ] `ui/widgets/question_popup.py`: text, choice and scale kinds; Skip, Back, Later; `Ctrl+Return` next, `Esc` later; frameless translucent card with drag via `startSystemMove()`; shown without activation for login prompts; 90-second auto-close counts as dismissed; 160 ms entry animation; progress text "Question n of m".
- [ ] Login prompt flow with the 2-hour cooldown after dismissal and one session per app start.
- [ ] "What Claude will be told" preview (read-only dialog showing the answers section from `handoff/answers.py`, once M2 is in place; use sample data if not).
- [ ] Register popup variants and the preview dialog with the snapshot tool.

**Tests first:** selection rules (no repeats, weighting, 14-day, exhausted pool, mix); template instantiation; scope selection returns 5 to 15 for every combination of options (files, web, academic, long, short, empty scope, empty audience); keyboard-only completion for each kind (pytest-qt); Back keeps answers; Later saves progress; Skip recorded as skipped.

**Acceptance**
1. All selection, mix and scope-selection rules pass their tests.
2. The popup is fully keyboard operable; snapshots of all three kinds in both themes match UI_DESIGN section 4.
3. Answers persist across restart.
4. The preview dialog shows the answers grouped as ARCHITECTURE section 5 describes.
